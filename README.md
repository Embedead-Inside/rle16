# Compact Bare-Metal RLE (16-bit)

[![License: MIT-0](https://shields.io)](https://spdx.org)
[![Language: C99](https://shields.io)](#)

C言語で書かれた、ベアメタル環境・マイコンデータストリーム（12ビットADCや各種センサーなど）に特化した、**極小・メモリ消費ゼロ・超高速**なランレングス圧縮（RLE）エンコーダ/デコーダです。

## 特徴

- **圧倒的なコードサイズ:** 複雑な条件分岐やインデックス計算を排除し、ポインタ演算とビット処理のみで構成された数行のコアロジック。
- **メモリ（RAM）消費ゼロ:** 静的・動的バッファ（`malloc` 等）を一切使用せず、CPUレジスタ内だけで処理が完結。
- **データ肥大化の防止:** データが全く連続しない最悪のケースでも、圧縮後のサイズが元のデータサイズを決して超えません（等倍を維持）。
- **32-bit CPU 最適化:** 内部カウンタや戻り値に `uint32_t` を採用。32ビット環境でのレジスタ処理を最速化し、65,535要素を超える巨大ストリームの処理にも対応。
- **コンパイル時設定:** 有効データビット数やRLEカウンタビット数を、`#define` マクロで簡単に調整可能。

## ビットパッキング構造（例：12ビット有効データの場合）

ポーリング（データ蓄積）の段階であらかじめ下位の不安定なノイズビットを切り捨てておくことで、1つの16ビットの箱の中に「RLEカウンタ」と「有効データ」をギューギューに詰め込みます。

```text
 15          12   11                          0
+----------------+-------------------------------+

| RLEカウンタ - 1 | 有効センサーデータ            |
| (4ビット: 1-16) | (12ビット: 0-4095)           |
+----------------+-------------------------------+
```

## 使い方

### 1. 設定
ヘッダファイル（`rle16.h`）で、事前に切り捨てられた有効センサーデータのビット幅を定義します。

```c
#define RLE16_VALID_BITS      12  // 例：12ビットADCデータ（下位4ビットノイズ切り捨て済み）
```

### 2. エンコード（圧縮）
データが溜まったバッファとその個数を渡します。戻り値として、生成された圧縮パケットの正確な個数が `uint32_t` で返ります。

```c
#include "rle16.h"

#define BUFFER_SIZE 1000
uint16_t raw_buffer[BUFFER_SIZE];  // 切り捨て済みの生データ (0-4095)
uint16_t comp_buffer[BUFFER_SIZE]; // 圧縮データが格納されるバッファ

void compress_sample(void) {
    // 圧縮後のパケット数が uint32_t で返ります
    uint32_t compressed_count = rle16_encode(raw_buffer, BUFFER_SIZE, comp_buffer);
}
```

### 3. デコード（復元）
圧縮バッファとパケット数を渡すことで、元のデータストリームに展開します。戻り値として、復元されたデータの総数が `uint32_t` で返ります。1つのバッファに連続して詰め込まれたストリームデータも正確に復元可能です。

```c
#include "rle16.h"

uint16_t decomp_buffer[BUFFER_SIZE]; // 復元データが格納されるバッファ

void decompress_sample(uint32_t compressed_count) {
    // 復元された元のデータ総数が uint32_t で返ります
    uint32_t restored_count = rle16_decode(comp_buffer, compressed_count, decomp_buffer);
}
```
